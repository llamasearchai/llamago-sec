# Installation

## Using pip

The recommended way to install LlamaGo Sec is via pip:

```bash
pip install llamago_sec
```

## From Source

You can also install LlamaGo Sec from source:

```bash
git clone https://github.com/llamasearchai/llamago-sec.git
cd llamago-sec
pip install -e .
```

## Dependencies

LlamaGo Sec requires:

- Python 3.8+
- Other dependencies are automatically installed by pip
